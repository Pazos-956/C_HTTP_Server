# PoC de Servidor HTTP escrito en C
El objetivo de este proyecto era hacer un PoC funcional de un servidor HTTP para aprender el uso de Sockets en C.


El servidor cuenta con un AVL Tree para guardar las rutas del servidor y permite servir páginas HTML estáticas con CSS.
# Referencias
- [Sockets en C](https://beej.us/guide/bgnet/html/)
